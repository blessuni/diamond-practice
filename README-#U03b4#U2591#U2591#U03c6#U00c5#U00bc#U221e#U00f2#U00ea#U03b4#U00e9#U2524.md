# 다이아몬드반 우리 모둠 마음보석 — Netlify 배포용

## 먼저 알아둘 점

이 폴더는 화면 파일뿐 아니라 공유 저장을 위한 Netlify 서버 함수를 포함합니다.
**Netlify Drop에 dist 폴더만 끌어 놓으면 화면만 배포되고, 태블릿 간 공유는 작동하지 않습니다.**
아래 CLI 방법 또는 Git 연결 방법으로 배포하세요. 별도의 Firebase/Supabase 계정이나 데이터베이스 API 키는 필요하지 않습니다.
Netlify 계정 로그인 및 해당 계정의 사이트 생성/선택은 선생님이 진행합니다.

## 가장 빠른 배포 — 완성 파일을 그대로 올리기

1. Node.js 22 이상을 설치하세요.
2. 이 폴더에서 터미널을 열고 아래를 실행하세요.

```sh
npm ci
npx netlify login
npm run deploy:ready
```

Netlify가 사이트를 물으면 새 사이트를 만들거나 사용할 사이트를 선택하세요.
완성된 dist 화면과 deploy-functions 서버 함수가 함께 올라갑니다.
Windows에서는 deploy.cmd, macOS/Linux에서는 bash deploy.sh로 같은 과정을 실행할 수 있습니다.
인증 토큰이나 비밀번호를 코드 파일에 넣지 마세요.

## Git 연결로 배포

1. 이 폴더 전체를 Git 저장소에 올립니다. node_modules와 .netlify는 올리지 않습니다.
2. Netlify에서 저장소를 연결합니다.
3. 설정은 netlify.toml에서 자동으로 읽습니다.
   - 빌드: npm run build
   - 화면 폴더: dist
   - 서버 함수: netlify/functions
4. 배포를 시작합니다. Netlify가 공유 저장소 연결 정보를 서버에 자동으로 제공합니다.

## 최종 활동 흐름

모둠 확인 → 2개 선택 → ① 진행자·② 감독·③ 촬영자·④ 올림이·⑤ 완성이 역할 확인 → 첫 보석 표현·촬영 → 하나 완성·다음 보석 안내 → 두 번째 보석 표현·촬영 → 두 보석 모두 ✓ 확인 → 모둠 자리 복귀 → 모였어요 → 기기의 사진 앱에서 함께 사진 확인 → 웹앱의 사진을 확인했어요 → 자기 모둠 색 Canva 안내 → 우리 사진 올리기 → Canva에서 사진 2장 업로드.

우리 사진 올리기가 웹앱의 마지막 행동입니다. Canva에 간 뒤 웹앱으로 돌아올 필요가 없고, 사진 올렸어요 버튼이나 추가 완료 화면도 없습니다.
사진 앱은 아이들이 직접 엽니다. 웹앱은 기기 사진 앱을 강제로 실행하거나 촬영 사진을 읽지 않습니다.

## 기록과 교사 진행상황

- 모든 태블릿에서 같은 Netlify 사이트 주소를 엽니다.
- 첫 보석만 완료한 때에는 자리 복귀·사진 확인·Canva 안내가 없습니다. 홈 복귀와 재실행 후에도 1/2 상태가 복원됩니다.
- 두 보석 촬영이 모두 끝난 경우에만 이후 화면이 열립니다.
- 오른쪽 위 「📊 진행상황 보기」를 한 번 누르면 전체 진행상황이 열립니다. 「↻ 새로고침」과 「← 돌아가기」 버튼을 제공합니다. 유아 4모둠과 참관교사 영역은 분리됩니다.
- 표시 단계: 오늘의 진행자 확인 → 마음보석 고르는 중 → 역할 확인 → 두 마음보석 표현 방법 의논 중 → 첫 번째 마음보석 표현 중 (0/2) → 두 번째 마음보석 표현 중 (1/2) → 두 마음보석 촬영 완료 (2/2) → 모둠 자리로 이동 → 사진 확인 → Canva 업로드 안내 → 🎨 Canva 업로드로 이동.
- Canva 이동은 링크를 누른 기록입니다. 외부 Canva의 실제 업로드 완료를 자동 확인하는 상태가 아닙니다.
- Netlify Functions와 site-wide Netlify Blobs 저장 구조는 그대로 유지합니다. localStorage는 기기별 이어하기와 연결 끊김 대비 기록을 보관합니다.
- 연결이 끊기면 새 진행 상태를 다른 기기에 공유할 수 없습니다. 재연결 또는 10초 간격으로 저장을 재시도합니다. 교사 화면은 4초 간격으로 저장된 서버 상태를 읽습니다.
- 보석별 완료 여부와 현재 화면, 역할 화면의 선택을 저장합니다. 사진·유아 이름은 저장하지 않습니다.
- 이전 완료 화면과 추가 선택 화면은 새 흐름으로 복원합니다. 기존의 보석 선택·완료 기록은 보존합니다. 한 개만 완료한 이전 업로드 상태는 표현 화면으로 돌아갑니다.
- 같은 Netlify 사이트에 다시 배포해야 기존 공유 기록이 유지됩니다.


## 검사 결과와 범위

총 18개 통과: 활동 조건·서버 기록 검사 13개와 다섯 모둠의 전체 화면 조작 검사 5개.
화면 검사는 실제 React 컴포넌트를 jsdom에 렌더링하고 버튼을 눌러 검사했습니다. 초기 선택·번호가 있는 역할·설명·촬영·자리 복귀·사진 확인·모둠 색 안내·Canva 링크 클릭의 저장·재실행 복원과 불필요한 복귀 버튼 부재를 확인했습니다.
운영 태블릿 브라우저의 실제 시각적 배치와 Canva 외부 편집 권한은 별도 확인이 필요합니다. 이 파일은 선생님의 Netlify 계정에 아직 배포되지 않았습니다.

공식 안내:
https://docs.netlify.com/build/data-and-storage/netlify-blobs/
https://docs.netlify.com/build/functions/get-started/

## 실제 앱 아이콘

첨부한 카메라·갤러리·Canva 앱 아이콘은 `public/app-icons/`와 빌드 결과 `dist/app-icons/`에 원본 그대로 포함됩니다. 외부 이미지 주소 없이 표시됩니다.

## 촬영 전 함께 의논

역할 확인 뒤에는 선택한 두 마음보석의 표현 방법을 함께 이야기합니다. 각 보석 아래에 장소·모습 질문이 있으며 「의논했어요! 촬영하러 출발」을 눌러 촬영을 시작합니다. 첫 보석 완료 후에는 두 번째 보석 촬영 안내와 완료 버튼이 바로 표시됩니다. 의논 단계도 저장·복원 및 교사 공유 조회에 포함됩니다. 이미 촬영 중이었던 이전 기록은 기존 단계에서 계속 이어집니다.

## 오늘의 진행자 및 교사 전체 초기화

새 모둠을 고르면 「오늘의 진행자는 누구일까요?」 화면에서 먼저 「🌟 오늘의 진행자 확인하기」 버튼이 표시됩니다. 버튼을 누르면 ① 진행자와 역할 그림·안내가 공개되고, 「① 진행자 준비됐어요!」 버튼으로 마음보석 선택 단계로 이동합니다. 확인 전에는 진행자 번호를 미리 보여주지 않습니다. 확인과 활동 진행은 저장되며 기존 진행 중인 모둠은 이어서 활동합니다.

「📊 진행상황 보기」 → 「🔄 전체 진행상황 초기화」 → 확인창의 「모두 초기화」를 누르면 유아 네 모둠과 참관교사용의 서버 기록을 삭제합니다. 초기화 버전을 서버와 기기에 저장하여 이전 버전의 기록 재전송을 거부합니다. 다른 태블릿은 새로고침·다시 접속·온라인 재연결 시 버전을 확인하고 로컬 활동 기록을 지운 뒤 모둠 선택부터 시작합니다. 기기 고유 식별자는 유지됩니다. 인터넷에 연결된 상태에서 전체 초기화를 실행해 주세요.

## 역할별 조작 안내

① 진행자는 친구들의 생각을 듣고 함께 정한 마음보석을 선택합니다. ② 감독은 역할 확인 뒤 두 마음보석의 표현 방법을 함께 정하고 출발 버튼을 누릅니다. ③ 촬영자는 첫 번째·두 번째 마음보석을 촬영하고 촬영을 마친 뒤 모둠 자리로 돌아가는 단계까지 태블릿을 조작합니다. ④ 올림이는 갤러리를 열어 모둠 친구들과 사진을 함께 확인한 뒤 Canva로 이동하여 두 사진을 자기 모둠 색 칸에 올립니다. ⑤ 완성이는 태블릿 조작 단계가 없으며, 이후 전체 모임에서 전자칠판으로 모둠 사진을 미덕송의 알맞은 자리에 넣습니다. 각 활동 화면의 왼쪽 위에는 현재 태블릿 조작 담당 번호와 역할이 크게 표시되며, 주요 활동 화면의 「← 뒤로」는 선택 내용을 유지한 채 바로 전 단계로 이동합니다. 기존 저장·공유 진행상황·전체 초기화 기능은 유지됩니다.
